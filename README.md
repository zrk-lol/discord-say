# discord-say

**Envoie un message dans un salon Discord depuis ton terminal (ou depuis un script).**

Zéro dépendance · Node.js 18+ · Windows, macOS, Linux.

## Utiliser tout de suite (sans rien installer)

```bash
echo "Déploiement OK" | npx github:zrk-lol/discord-say
```

## Installer la commande `discord-say`

```bash
npm install -g github:zrk-lol/discord-say
echo "Déploiement OK" | discord-say
```
